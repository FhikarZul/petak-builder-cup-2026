# Petak submission visuals

These two 16:9 SVG slides provide a short visual introduction for Builder Cup reviewers. They are adapted from the business-card presentation's idea of a Petak introduction, rather than copied slides or screenshots of a running app.

1. [`petak-introduction.svg`](petak-introduction.svg) introduces the product with the current Petak mark, wordmark, and approved tagline.
2. [`product-flow.svg`](product-flow.svg) summarizes the product's public integration boundary. The private Petak API and execution services are shown by role only; the separate Vertex AI example in this repository is not part of that product flow.

The slides use the public client design tokens and the Petak logo files already included in this repository. The original presentation's personal contact information, sample address, QR code, alternate tagline, and unverified illustration assets are not included. The logo remains subject to the [Petak brand asset notice](../../packages/assets/README-LICENSE.md). For implementation detail and judge access, use the [architecture](../architecture.md) and [demo flow](../demo-flow.md).
