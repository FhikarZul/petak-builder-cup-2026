# Components intentionally private

The public repository excludes Petak's production API and execution workers, system prompts and neighbour manifests, orchestration and workflow policies, AI evaluation corpus, database schema and migrations, billing and business rules on the server, Cloud Run deployment operators, infrastructure configuration, credentials, signing material, and internal decision records.

The public app still shows product UI and client-side behavior. Its source is available under the limited evaluation terms in `apps/app/LICENSE`; Petak brand assets remain proprietary under `packages/assets/README-LICENSE.md`. Ownership and publication rights for selected artwork still need final review. The standalone Vertex AI example has its own Apache-2.0 license.
