# Petak submission visuals

This folder contains a short visual introduction for Builder Cup reviewers and two selected slides exported from the supplied business-card presentation.

1. [`petak-introduction.svg`](petak-introduction.svg) introduces the product with the current Petak mark, wordmark, and approved tagline.
2. [`product-flow.svg`](product-flow.svg) summarizes the product's public integration boundary. The private Petak API and execution services are shown by role only; the separate Vertex AI example in this repository is not part of that product flow.

The SVG slides use the public client design tokens and the Petak logo files already included in this repository.

## Selected business-card slides

These are rendered exports of **slides 1 and 2** from `Bussiness Card.pptx`, supplied separately for this submission. The old tagline on each was replaced with the current wording, "Everything, in its petak." They are deck-derived design concepts; the SVG introduction above uses the current client tokens and logo exports.
